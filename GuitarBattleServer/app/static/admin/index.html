    Пересчёт не меняет XP, уровни, достижения и награды — только снимок Guitar Skills и записи истории рейтинга. Повторный запуск идемпотентен.

    Пересчитать всех игроков?

    Будет пересчитан Guitar Skills каждого активного игрока по текущим параметрам формулы. Изменения запишутся в историю рейтинга.

    • XP, уровни, достижения и награды не меняются.
    • Старые записи не удаляются, повторный запуск идемпотентен.
    • Пока идёт пересчёт, второй запуск вернёт конфликт.

    Сначала выполните Dry Run: он покажет старые и новые значения и места без записи.
