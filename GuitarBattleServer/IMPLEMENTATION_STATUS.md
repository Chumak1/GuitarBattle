# Реализация пяти этапов GuitarBattle

## Реализовано в этом обновлении

1. **Каталог песен:** сохранён публичный каталог; добавлена кнопка `LOAD ONLINE SONG` в JUCE. Она получает список опубликованных песен, загружает детали и MIDI, сохраняет MIDI в кэш пользователя и передаёт файл в существующий `MidiParser`.
2. **API и права доступа:** существующие административные маршруты остаются защищены JWT и `is_admin`; публичный каталог не показывает черновики. Добавлены проверки владения игровой сессией и диапазоны значений результатов.
3. **Интеграция JUCE:** клиент умеет загружать MIDI опубликованной песни с `http://localhost:8000`. Локальный выбор песен и локальный рекорд сохранены.
4. **Аккаунты и результаты:** сервер поддерживает регистрацию, вход, профиль (`GET/PATCH /auth/me`), создание/завершение игровых сессий, историю и сохранение результата.
5. **Рейтинг:** сервер поддерживает глобальный рейтинг игроков и рейтинг по песне. Эндпоинты комнат не включены в маршрутизатор API.

## Что ещё не подключено в интерфейсе JUCE

В этой версии JUCE-интерфейс не содержит экранов регистрации/входа и не отправляет игровые результаты на сервер автоматически. Эти API уже доступны и описаны в `GuitarBattleServer/README.md`, но полноценный клиентский аккаунтный workflow требует следующего отдельного шага. Эндпоинты комнат соревнований отключены в маршрутизаторе API и не входят в текущий план.

Результаты принимаются от клиента и не защищены от подмены. Не используйте этот механизм как доверенный публичный рейтинг без серверной валидации результатов.

## Проверки

- Python-файлы прошли `compileall`.
- Полный запуск API и миграций в этой среде не подтверждён: для проверки необходимы установленные зависимости из `requirements.txt`, PostgreSQL и Docker Compose.
- C++ сборка не подтверждена: в присланном архиве нет `.jucer` и файлов проекта Visual Studio, а JUCE SDK доступен только в локальной среде пользователя. После замены исходников выполните сборку в Visual Studio; если компилятор выдаст ошибки, пришлите полный список.


## Глобальный рейтинг на главном экране (добавлено)

- Добавлен публичный `GET /api/v1/leaderboard/global?limit=10&offset=0`.
- Рейтинг пользователей сортируется по сумме очков за завершённые игры на опубликованных песнях; рядом показываются число игр и имя пользователя.
- На главном экране JUCE добавлены блок GLOBAL PLAYER RATING и кнопка REFRESH RATING. Кнопка загружает рейтинг с локального API `http://localhost:8000`.
- Если сервер недоступен или результатов ещё нет, интерфейс показывает соответствующее сообщение.
- Проверка `compileall` для Python-кода прошла. C++/JUCE-сборка в этой среде не выполнялась; после замены исходников требуется Rebuild Solution в Visual Studio.


## Клиентская интеграция аккаунтов и результатов

API `/auth/register`, `/auth/login`, `/auth/me`, `/games/sessions` и `/games/sessions/{id}/finish` теперь используются JUCE-клиентом: после входа/регистрации он может создать сессию для опубликованной онлайн-песни и отправить результат после завершения. Серверная схема API не менялась в этом шаге. Подмена результатов клиентом по-прежнему возможна; необходима серверная валидация для публичных соревнований.


## MP3 instrumental stems

- Public song details expose download URLs for the latest stored file per role: `midi`, `drums`, `bass`, `guitar`, `others`.
- Admins can upload `.mp3` stems via `POST /api/v1/admin/songs/{song_id}/files/audio/{role}` (roles: `drums`, `bass`, `guitar`, `others`; limit: 100 MiB).
- The JUCE client downloads available stems into `%APPDATA%/GuitarBattle/OnlineSongs/<slug>/` and reuses cached files when the size matches the server metadata. The mixer maps `guitar` to the rhythm-guitar channel.
- MP3 stems are optional; songs with only MIDI continue to load as before.
